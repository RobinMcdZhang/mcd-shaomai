# 捎麦（Shaomai）· 麦麦堂食捎带

办公室场景下的麦麦「拼车取餐」工具：一个人当**发车人**去餐厅取餐，同楼同事凭 6 位单号**上车**顺带，各自的取餐码自动汇总到看板，司机一次取齐、回办公室按昵称分发。

> **本质是取餐物流拼单，不是付款拼单**——每人各自在麦当劳 MCP 下自己的单、各自付款，司机只负责物理取餐 + 分发。

基于[麦当劳官方 MCP](https://open.mcd.cn/mcp/doc)（每人独立 Token）与一个轻量共享协调后端（Cloudflare Worker + D1，自带看板）。

🌐 **服务看板：[https://shaomai.win](https://shaomai.win/)** —— 公共服务端，后端地址已内置于 skill，装完即用（也支持自建）。看板数据全局可读，勿发布敏感信息。

## 目标用户

- **办公楼里的「干饭搭子」**：同一栋写字楼、同一家麦当劳门店，经常互相带饭的同事。
- **不想装 App、不想拉群对码的人**：直接在 WorkBuddy 对话里完成发车、上车、盯码，取餐码自动汇总。
- **麦当劳 MCP 的轻度高频用户**：已经在用麦当劳官方 MCP 下单，想把「跟单取码」这一步自动化的个人/小团队。

## 快速开始

**1. 每人配置 Skill**

- 去 <https://open.mcd.cn> 申请自己的麦当劳 MCP Token（MCP 每人独立账户）；
- 把 `skill/` 目录放入 WorkBuddy 技能目录（见 [`skill/README.md`](skill/README.md)）。

**2. 跑起来**

对 WorkBuddy 说：「捎麦，我要发车，门店 MCD001，最多 3 人，12:30 出发」→ 把 6 位单号发到办公室群 → 同事说「捎麦，上车 X1X2X3」→ 各自同门店下单 → 盯码自动推看板 → 司机看「🎫 取餐码汇总」到齐后取餐分发。

## 工作流

```
发车人: Skill → mcd-mcp 下单 ──┐
                                ├─→ 共享后端(Worker+D1) ──→ 看板(只读协同展示)
乘客:   Skill → mcd-mcp 下单 ──┘        ↑
        Skill 每10秒盯取餐码 → 出码推送 ──┘
```

- **同店硬约束**：一个顺路单锚定一个门店，所有人必须同门店下单（取餐能一次取齐的前提）。
- **顺带判定**：同店前提下，由 LLM 比较双方楼栋文本给「软建议」，最终由发车人决定，不做自动拒绝。
- **防滥用**：发车需服务端发放的一次性票据（限流、一票一单）；写取餐码/下车需成员密钥、状态流转/踢人需司机密钥；读操作全开放。

## 安全与隐私

- 跨用户只暴露**楼栋标签 + 昵称 + 楼层**，完整门牌/电话不进看板与接口响应。
- 密钥仅存于使用方本地（`shaomai_state.json`），**勿提交、勿外传**。
- 每 Token 限流 600 次/分；盯码轮询 10 秒一次（6/min）远低于上限。
